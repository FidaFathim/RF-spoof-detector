PROPOSED METHODOLOGY

What we tested

Real data

WiSig ManySig: 6 transmitters, 12 receivers, 4 capture days, 288,000 signals.

No leakage

Split by session (day and receiver), never by packet: 174k train, 60k validation, 54k test.

Attacks

FGSM, PGD, UAP, all claiming to be one device (14-10). Full access to the CNN, fed straight in.

Rigor

3 random seeds. Thresholds set on validation only. The check never sees an attack.

RF spoof detection · 8

Four things to say. Data: a public dataset with real captured radio signals. Splitting: we split by capture session, not by random packet, because packets from the same session share the same channel and would leak information. Attacks: all three attacks assume the attacker knows the CNN and feeds the perturbed signal directly to it; we did not test over-the-air transmission. Rigor: three seeds, thresholds tuned on validation data only, and the physics gate is trained only on genuine signals.
