What this means

At ε=0.1 the check rejects attacks about as often as a plain wrong-device signal or random noise. It does not see the perturbation there. Only large attacks clearly stand out.

RF spoof detection · 14 · Seed 0, 12,000 test signals. Bars: 1% = 6 px

This is the control experiment that separates 'wrong device' from 'attack'. We fed the check signals that are not attacks at all. Unperturbed signals from other devices claiming to be device 14-10 are rejected 15.8 percent of the time; plain random noise at epsilon 0.1 is rejected 15.9 percent. A PGD attack at epsilon 0.1 is rejected 16.7 percent, essentially the same. So at small epsilon the check is not detecting the attack, it is reacting to any signal that does not look like the claimed device. At epsilon 0.4 PGD stands out clearly, 78 percent against 20 percent for noise, so the check does react to large, structured perturbations, mainly through I/Q phase. This is a limitation we state ourselves, and it is a useful answer if someone asks whether the check really detects attacks.
