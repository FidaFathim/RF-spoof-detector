NOVELTY

What is new, in plain words

Our contribution

  • A separate physical cross-check beside the classifier, per device, that does not rely on the classifier's confidence
  • Trained only on genuine signals, so it needs no attack examples
  • Tested honestly: control experiments, fair comparisons, 3 seeds, negative results reported

Not ours (prior work)

  • CNN fingerprinting and the FGSM, PGD, UAP attacks
  • CFO, I/Q imbalance and phase noise as features
  • Closest defense: Yang et al. 2024 compares two classifiers using one feature

Hypothesis tested: a forged signal that fools the CNN does not match real hardware, so a second check can catch it. Partly supported. Details follow.

RF spoof detection · 5

Say this plainly. Plain version of the novelty: existing systems rely on one neural network to decide who is transmitting, and that network can be fooled. We add a second, independent check that asks whether the hardware flaws look like the claimed device. It is trained only on genuine signals, so it does not need to know any attack in advance. Be honest about what is not ours: the CNN, the attacks and the features are all prior work. Our original idea was that the relationship between several features is what makes the check work; our own tests did not support that, and I will show it. What survives is narrower: a separate, per-device physical check that works where classifier confidence fails.
